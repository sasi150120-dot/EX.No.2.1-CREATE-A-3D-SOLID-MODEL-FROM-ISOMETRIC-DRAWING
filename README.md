# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date:

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE


1. Open the **Autodesk Fusion 360** software.

2. Click on **File → New Design** to create a new design.

3. Select the **XY Plane** and click on **Create Sketch**.

<img width="406" height="666" alt="Screenshot 2026-11-16 015257" src="https://github.com/user-attachments/assets/6ec88bf6-02a6-4831-b95c-77c17c224c79" />

4. Draw the rectangular base profile using the **Rectangle Tool** according to the given dimensions.

<img width="76" height="41" alt="Screenshot 2026-11-16 024958" src="https://github.com/user-attachments/assets/f799f735-deed-43da-a360-99ea7ae1ab8f" />

5. Apply the required dimensions using the **Sketch Dimension Tool (D)**.

6. Click on **Finish Sketch** and use the **Extrude Tool (E)** to give the required thickness to the base.

<img width="146" height="61" alt="Screenshot 2026-11-16 020758" src="https://github.com/user-attachments/assets/85ee6c7e-dee8-4ae1-af55-37bb30bd918e" />

7. Select the front face and create a circle of diameter **50 mm** using the Circle Tool.

8. Use the **Extrude Tool** to create the cylindrical projection on the front side of the component.

9. Select the top face and draw a circle of diameter **20 mm** at the required position.

10. Use the **Extrude Tool** to create the circular raised portion on the top surface.

<img width="52" height="57" alt="Screenshot 2026-11-16 025216" src="https://github.com/user-attachments/assets/6572d5b3-e4b1-424f-b3c3-cf35c4c837df" />

11. Create the upper inclined block using the **Sketch Tool** and **Extrude Tool**.

12. Apply the required inclined angle of **45°** to the sloping portion.

13. Draw the small rectangular block on the upper-left portion using the **Rectangle Tool** and apply extrusion.

<img width="76" height="41" alt="Screenshot 2026-11-16 024958" src="https://github.com/user-attachments/assets/08288770-75b6-4f28-bc31-4f1800a3e16f" />

14. Use the required dimensions and positioning tools to complete the remaining features.

15. Check the model and make sure all the features match the given isometric drawing.

16. Apply the required appearance if necessary and save the completed design using **File → Save**.
